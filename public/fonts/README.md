# 首页诗词字体

pathly-poems.ttf 是 Google Fonts 提供的 Noto Serif SC（思源宋体同源项目）400 字重文本子集，仅包含首页四组诗词所需字符，约16.4KiB。

上游：https://github.com/google/fonts/tree/main/ofl/notoserifsc
获取方式：Google Fonts CSS2 API，family=Noto Serif SC:wght@400，text=首页诗词字符。
许可：SIL Open Font License 1.1，见 OFL-NotoSerifSC.txt。

字体在本站加载，font-display: swap。网络/字体失败时回退到 Noto Serif SC、Source Han Serif SC、宋体及系统 serif。不改变首页其他文字字体。
`pathly-search-serif.woff2`: search heading subset of the same Adobe Source Han Serif CN Regular (400), renamed PathlySearchSerif; OFL-SourceHanSerif.txt applies. Includes every glyph in 把向往，安排成旅程。. No runtime third-party font request.
