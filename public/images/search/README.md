lantingxu-ink.webp: derived locally using scripts/prepare-lanting.py. Local paper brightness estimation and continuous alpha extraction; no generated lettering, no tracing, no rearrangement, no shape deformation. Original retained at full resolution; display derivative proportionally reduced to 2600px wide. Fine paper stains and some stamp traces can remain; pale ink cannot be perfectly separated from aged paper. Lossless WebP after proportional resampling.
lantingxu-proof.jpg is a cream-background inspection proof only, not used by the webpage.
The actual component lazily decodes the transparent WebP when approaching the search section. Only mask coordinates move, the background image does not move. Original JPEG and proof are not fetched at runtime.
